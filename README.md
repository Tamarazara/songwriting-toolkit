# Songwriting Toolkit

A lightweight browser-based songwriting workspace for developing lyrics, structure, hooks, rhyme ideas, vocal notes, and production concepts.

## Features
- Song title, theme, chords, and tempo
- Verse, pre-chorus, chorus, bridge, and outro sections
- Hook and creative-writing prompts
- Rhyme scheme and imagery notes
- Vocal-performance notes
- Production and arrangement notes
- Browser draft saving
- Lyric export to a text file

## Run It
Open `index.html` in any web browser.

## Publish Free with GitHub Pages
1. Create a public GitHub repository named `songwriting-toolkit`.
2. Upload all four files.
3. Open **Settings > Pages**.
4. Choose **Deploy from a branch**.
5. Select `main` and `/root`, then save.

## Creative Philosophy
Technology should support imagination rather than replace it. This toolkit helps songwriters organize ideas, experiment creatively, and move from inspiration toward a finished song.
